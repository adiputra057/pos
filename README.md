# POS — Point of Sale System

Sistem **Point of Sale (POS)** berbasis web yang dirancang untuk membantu bisnis **F&B dan Retail** dalam mengelola transaksi penjualan, produk, stok, pelanggan, serta laporan bisnis secara lebih mudah dan efisien.

## 🚀 Fitur Utama

* 🛒 **Point of Sale (POS)** — Proses transaksi penjualan dengan cepat.
* 📦 **Manajemen Produk** — Kelola produk, kategori, harga, dan SKU.
* 📊 **Manajemen Stok** — Pantau stok masuk, stok keluar, dan ketersediaan produk.
* 👥 **Manajemen Pelanggan** — Simpan dan kelola data pelanggan.
* 💳 **Metode Pembayaran** — Mendukung berbagai metode pembayaran.
* 🧾 **Struk Transaksi** — Cetak atau simpan bukti transaksi.
* 📈 **Laporan Penjualan** — Pantau transaksi dan performa penjualan.
* 👤 **Manajemen User & Role** — Pengaturan akses berdasarkan hak pengguna.
* ⚙️ **Pengaturan Toko** — Kelola informasi dan konfigurasi bisnis.
* 📱 **Responsive Design** — Dapat digunakan melalui desktop, tablet, maupun perangkat mobile.

## 🎯 Target Pengguna

Sistem ini cocok digunakan untuk:

* 🍜 Restaurant & Café
* 🥤 F&B
* 🛍️ Retail Store
* 🏪 Minimarket
* 👕 Fashion Store
* 💻 Toko Komputer & Elektronik
* 📦 Usaha kecil dan menengah (UMKM)

## 🛠️ Teknologi

Project ini dikembangkan menggunakan teknologi web modern untuk menghasilkan sistem POS yang cepat, fleksibel, dan mudah dikembangkan.

**Tech Stack:**

* Laravel
* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap / Tailwind CSS

## 📌 Tujuan Project

Membangun sistem POS yang dapat membantu pemilik usaha mengelola operasional toko secara terintegrasi, mulai dari **transaksi, produk, stok hingga laporan penjualan** dalam satu sistem.
